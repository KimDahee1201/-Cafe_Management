# Pixel Cafe Tycoon

픽셀 아트 카페를 직접 운영하는 브라우저 기반 3인칭 타이쿤 게임입니다. 손님 주문에 맞춰 커피와 베이커리를 만들고 서빙해 골드와 평판을 모으세요. 직원을 고용해 업무를 자동화하고 매장을 확장해 최종 목표인 **1,000,000 골드**에 도전할 수 있습니다.

## 주요 기능

- **카페 운영:** 원두와 반죽을 가져와 커피를 추출하거나 빵을 굽고, 카운터 또는 테이블 손님에게 주문한 메뉴를 제공합니다.
- **메뉴 해금과 매장 확장:** 1단계에서는 아메리카노를 판매하고, 확장에 따라 카페라떼·크루아상·딸기 조각케이크와 새 설비를 해금합니다.
- **직원 고용 및 자동화:** 바리스타, 파티시에, 서빙 매니저, 고양이 청소 직원을 고용하고 강화할 수 있습니다.
- **성장 시스템:** 퀘스트 보상, 시설 및 재료 업그레이드, 평판 관리, 영업 결산으로 카페를 성장시킵니다.
- **픽셀 아트 화면:** Canvas 2D로 카페와 캐릭터를 그리며 플레이어를 따라가는 카메라와 화면 확대·축소를 지원합니다.
- **데스크톱·모바일 조작:** 키보드와 마우스, 터치 가상 조이스틱을 지원합니다. 효과음과 배경 음악은 Web Audio API로 생성합니다.

## 기술 스택

- React 19, TypeScript
- Vite 8
- Canvas 2D, Web Audio API
- Tailwind CSS 4
- lucide-react, Motion

## 시작하기

필요한 도구는 Node.js와 npm입니다.

```bash
git clone https://github.com/KimDahee1201/-Cafe_Management.git
cd -Cafe_Management
npm install
npm run dev
```

개발 서버는 `http://localhost:3000`에서 열립니다. 프로덕션 빌드와 미리보기는 다음 명령으로 실행합니다.

```bash
npm run build
npm run preview
```

TypeScript 타입 검사는 다음과 같이 실행할 수 있습니다.

```bash
npm run lint
```

## 조작 방법

| 입력 | 동작 |
| --- | --- |
| `W` `A` `S` `D` 또는 방향키 | 캐릭터 이동 |
| 마우스 클릭 또는 화면 탭 | 클릭한 위치로 이동 |
| `Space` 또는 `E` | 가까운 작업대와 상호작용 |
| 모바일 가상 조이스틱 | 캐릭터 이동 |
| 모바일 `작업` 버튼 | 가까운 작업대와 상호작용 |
| 화면의 `+` / `-` 버튼 | 게임 화면 확대 / 축소 |

## 영업 시작하기

1. 원두 창고에서 원두를 가져옵니다.
2. 에스프레소 머신에서 커피를 추출합니다. 매장을 확장하면 오븐으로 베이커리 메뉴도 만들 수 있습니다.
3. 완성한 메뉴를 카운터 대기 손님이나 테이블 손님에게 제공합니다.
4. 테이블의 빈 그릇을 수거해 개수대에서 세척하면 위생과 평판을 관리할 수 있습니다.
5. 골드와 평판을 모아 직원을 고용하고 장비를 강화하거나 매장을 확장합니다.

## 프로젝트 구조

```text
src/
├── App.tsx                    # 게임 엔진 초기화, 화면 상태와 모달 구성
├── main.tsx                   # React 애플리케이션 진입점
├── index.css                  # 전역 스타일 및 픽셀 아트 스타일
├── components/
│   ├── GameCanvas.tsx         # Canvas 렌더링, 카메라 및 키보드·마우스 입력
│   ├── HUD.tsx                # 골드·평판·시간·인벤토리와 메뉴 표시
│   ├── VirtualJoystick.tsx    # 모바일 터치 이동 및 작업 버튼
│   └── *Modal.tsx             # 업그레이드, 직원, 퀘스트, 메뉴 및 결산 모달
└── game/
    ├── engine.ts              # 게임 루프, 이동, 손님·직원 행동과 경제 시뮬레이션
    ├── sprites.ts              # Canvas 픽셀 아트 렌더링
    ├── audio.ts                # Web Audio API 효과음과 배경 음악
    ├── constants.ts            # 메뉴, 직원, 확장 단계 및 퀘스트 데이터
    └── types.ts                # 게임 상태와 엔티티 타입
```

`App.tsx`가 `GameEngine`을 생성하고 상태 변경을 HUD와 모달에 연결합니다. `GameEngine`은 게임 시간, 플레이어 이동, 작업대 상호작용, 손님 주문·대기, 직원 자동화와 보상 처리를 담당합니다. `GameCanvas`는 엔진의 상태를 매 프레임 픽셀 아트로 그리며, `constants.ts`의 데이터로 메뉴와 성장 콘텐츠를 구성합니다.
