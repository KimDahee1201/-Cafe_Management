# Pixel Cafe Tycoon

픽셀 아트 카페를 직접 운영하는 브라우저 기반 타이쿤 게임입니다. 손님 주문에 맞춰 커피를 추출하고 음식을 서빙해 골드와 평판을 쌓으며, 직원을 고용하고 매장을 확장해 최종 목표인 **1,000,000 골드** 달성에 도전하세요.

## 주요 기능

- **카페 운영 시뮬레이션:** 손님의 주문과 인내심, 매장 영업 시간, 러시 아워를 관리합니다.
- **직접 만드는 메뉴:** 원두를 가져와 아메리카노를 추출하고, 매장 확장 후 라떼·크루아상·딸기 케이크를 준비합니다.
- **매장 확장:** 평판과 골드를 모아 총 3단계의 매장을 열고 새로운 조리 설비와 좌석을 해금합니다.
- **직원 자동화:** 바리스타, 파티시에, 서빙 매니저, 고양이 청소 직원을 고용하고 강화할 수 있습니다.
- **성장 및 업적:** 장비·재료 업그레이드, 퀘스트 보상, 일일 영업 결산과 승리 화면을 제공합니다.
- **픽셀 아트와 오디오:** Canvas 기반 픽셀 그래픽, 카메라 확대/축소, Web Audio API로 생성하는 효과음과 배경 음악을 지원합니다.
- **데스크톱 및 모바일 조작:** 키보드·마우스와 터치 조이스틱을 지원합니다.

## 기술 스택

- React 19, TypeScript, Vite 8
- Canvas 2D를 사용한 게임 화면 렌더링
- Tailwind CSS 4
- lucide-react 아이콘, Motion 애니메이션 라이브러리

## 시작하기

필요 환경: Node.js와 npm

```bash
git clone https://github.com/KimDahee1201/-Cafe_Management.git
cd -Cafe_Management
npm install
npm run dev
```

개발 서버는 `http://localhost:3000`에서 실행됩니다. 빌드와 빌드 결과 미리보기는 다음 명령으로 실행할 수 있습니다.

```bash
npm run build
npm run preview
```

TypeScript 타입 검사는 다음 명령을 사용합니다.

```bash
npm run lint
```

## 조작 방법

| 입력 | 동작 |
| --- | --- |
| `W` `A` `S` `D` 또는 방향키 | 캐릭터 이동 |
| 마우스 클릭 또는 화면 탭 | 이동할 위치 지정 |
| `Space` 또는 `E` | 가까운 작업대와 상호작용 |
| 모바일 화면의 가상 조이스틱 | 캐릭터 이동 |
| 모바일 화면의 작업 버튼 | 가까운 작업대와 상호작용 |

게임 안에서는 원두 창고에서 재료를 챙기고 에스프레소 머신에서 커피를 만든 뒤, 계산대 대기 손님 또는 테이블 손님에게 주문한 메뉴를 건네세요. 테이블의 빈 그릇은 직접 수거해 개수대에서 씻을 수 있습니다. 영업 수익과 평판을 바탕으로 직원·장비·매장 확장을 이용하세요.

## 프로젝트 구조

```text
src/
├── App.tsx                 # 게임 상태와 화면, HUD 및 모달 구성
├── main.tsx                # React 앱 진입점
├── index.css               # Tailwind 및 픽셀 스타일
├── components/             # Canvas, HUD, 조작 UI, 관리 모달
└── game/
    ├── engine.ts           # 게임 루프, 이동, 손님·직원 AI, 경제 및 퀘스트
    ├── sprites.ts          # Canvas 픽셀 아트 렌더링
    ├── audio.ts            # Web Audio 기반 효과음과 배경 음악
    ├── constants.ts        # 메뉴, 가격, 직원, 확장 단계, 퀘스트 데이터
    └── types.ts            # 게임 상태 및 엔티티 타입
```

## 개발 스크립트

| 명령 | 설명 |
| --- | --- |
| `npm run dev` | Vite 개발 서버 실행 (포트 3000) |
| `npm run build` | 프로덕션 빌드 생성 |
| `npm run preview` | 프로덕션 빌드 미리보기 |
| `npm run lint` | TypeScript 타입 검사 (`tsc --noEmit`) |
| `npm run clean` | `dist` 및 `server.js` 삭제 |

게임 시뮬레이션과 진행 상태는 현재 브라우저의 `GameEngine`에서 관리됩니다. 저장 기능이나 별도의 백엔드 실행 절차는 구현 코드에서 확인되지 않았습니다.
