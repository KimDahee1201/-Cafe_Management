# Pixel Cafe Tycoon

픽셀 아트 카페를 직접 운영하는 브라우저 기반 3인칭 타이쿤 게임입니다. 손님이 원하는 메뉴를 만들고 서빙해 골드와 평판을 모으세요. 직원을 고용하고 매장을 확장해 최종 목표인 **1,000,000 골드**에 도전할 수 있습니다.

## 주요 기능

- **직접 운영하는 카페:** 원두를 가져와 커피를 추출하고, 손님에게 주문한 메뉴를 건네며 영업합니다.
- **다양한 메뉴:** 아메리카노로 시작해 매장을 확장하며 카페라떼, 크루아상, 딸기 케이크를 해금합니다.
- **매장 확장:** 평판과 골드를 조건에 맞게 모아 총 3단계의 카페를 운영하고 새로운 메뉴와 설비를 엽니다.
- **직원 고용 및 자동화:** 바리스타, 파티시에, 서빙 매니저, 고양이 청소 직원을 고용하고 업그레이드할 수 있습니다.
- **성장 콘텐츠:** 퀘스트, 업그레이드, 영업 결산, 평판 및 골드 목표를 통해 카페를 성장시킵니다.
- **픽셀 아트 게임 화면:** Canvas 2D 렌더링, 플레이어를 따라가는 카메라, 화면 확대·축소를 지원합니다.
- **웹 오디오:** Web Audio API 기반 효과음과 배경 음악을 제공합니다.
- **데스크톱 및 모바일 조작:** 키보드·마우스 입력과 모바일 터치 조이스틱을 지원합니다.

## 기술 스택

- React 19, TypeScript
- Vite 8
- Canvas 2D, Web Audio API
- Tailwind CSS 4
- lucide-react, Motion

## 시작하기

필요한 도구: Node.js와 npm

```bash
git clone https://github.com/KimDahee1201/-Cafe_Management.git
cd -Cafe_Management
npm install
npm run dev
```

개발 서버는 `http://localhost:3000`에서 열립니다. 프로덕션 빌드와 빌드 결과 확인은 다음과 같이 실행할 수 있습니다.

```bash
npm run build
npm run preview
```

TypeScript 타입 검사는 다음 명령으로 실행합니다.

```bash
npm run lint
```

## 조작 방법

| 입력 | 동작 |
| --- | --- |
| `W` `A` `S` `D` 또는 방향키 | 캐릭터 이동 |
| 마우스 클릭 또는 화면 탭 | 클릭한 위치로 이동 |
| `Space` 또는 `E` | 가까운 작업대와 상호작용 |
| 화면의 `+` / `-` 버튼 | 게임 화면 확대 / 축소 |
| 모바일 가상 조이스틱 | 캐릭터 이동 |
| 모바일 `작업` 버튼 | 가까운 작업대와 상호작용 |

### 영업 시작하기

1. 원두 창고로 이동해 원두를 챙깁니다.
2. 에스프레소 머신에서 커피를 추출합니다.
3. 완성한 메뉴를 카운터 대기 손님이나 테이블 손님에게 서빙합니다.
4. 손님이 떠난 뒤 빈 접시와 컵을 개수대에서 정리해 위생과 평판을 관리합니다.
5. 골드와 평판을 모아 직원을 고용하고 매장을 확장합니다.

## 프로젝트 구조

```text
src/
├── App.tsx                    # 게임 상태, HUD 및 모달 구성
├── main.tsx                   # React 애플리케이션 진입점
├── index.css                  # 전역 스타일 및 픽셀 아트 스타일
├── components/
│   ├── GameCanvas.tsx         # Canvas 렌더링, 키보드·마우스 입력
│   ├── HUD.tsx                # 게임 상태와 주요 메뉴 표시
│   ├── VirtualJoystick.tsx    # 모바일 터치 조작
│   └── *Modal.tsx             # 업그레이드, 직원, 퀘스트 등 모달
└── game/
    ├── engine.ts              # 게임 루프, 이동, 손님·직원 행동 및 시뮬레이션
    ├── sprites.ts             # Canvas 픽셀 아트 렌더링
    ├── audio.ts               # 효과음 및 배경 음악
    ├── constants.ts           # 메뉴, 직원, 확장 단계 및 퀘스트 데이터
    └── types.ts               # 게임 상태와 엔티티 타입
```

## 개발 스크립트

| 명령 | 설명 |
| --- | --- |
| `npm run dev` | Vite 개발 서버 실행 (포트 3000) |
| `npm run build` | 프로덕션 빌드 생성 |
| `npm run preview` | 프로덕션 빌드 미리보기 |
| `npm run lint` | TypeScript 타입 검사 (`tsc --noEmit`) |
| `npm run clean` | `dist` 및 `server.js` 삭제 |

게임은 브라우저에서 동작하며, 시뮬레이션은 `GameEngine`이 관리합니다.
